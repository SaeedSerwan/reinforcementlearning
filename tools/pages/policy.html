Policy gradients and actor–critic.

Back to the direct idea: keep a probability for every action and adjust the probabilities themselves. Push up what did well, push down what did badly. Then combine both routes: an actor that chooses and a critic that judges.

02The baseline problem

"Push up actions with good returns" needs to know what counts as good. Picture three adverts that bring 2, 4 and 6 clicks per hour on average: easy, advert C wins. Now add a constant to every reward, say +50: 52, 54, 56. Nothing about which advert is better has changed, but every advert now looks like a big success. Try it.

A learner that pushes probabilities

Three adverts; the learner sees rewards (plus a little noise) and adjusts the probabilities directly. Step size 0.03, 300 updates, average of 200 runs.

Q-learning only asks which value is the largest

So the baseline is not decoration. For Q-learning the offset never mattered: it only asks which value is largest. A policy gradient moves probabilities by how much each action was worth, so it needs "better or worse than usual".

Key idea: a return is only good or bad compared with what was expected. Subtracting a baseline makes that comparison.

03No target to aim at: an objective

When we learned values, there was always a target to move towards. For a policy there is none: nobody knows the "correct" probability of going left. So instead of a loss to minimise we pick something to maximise: the objective \(J(\theta)\), how much reward the policy collects on average. \(\theta\) are the policy's adjustable numbers. Sources define J in several ways; they all mean the same thing:

\(J(\theta) = \mathbb{E}[G_0]\)the expected total reward of a whole episode
\(J(\theta) = V_\pi(s_0)\)the value of the start state
\(J(\theta) = \sum_s d_\pi(s)\, V_\pi(s)\)the average value of the states the policy visits
\(J(\theta) = \lim_{T\to\infty} \tfrac{1}{T}\,\mathbb{E}\big[\sum_{t=1}^{T} R_t\big]\)the average reward per time step (tasks that never end)

The learning curves on this site are pictures of J. Computing J is easy and not very useful; the point is the direction in which to change θ to make J go up: gradient ascent.

04The policy gradient

Working out that direction (the policy gradient theorem) gives a result of this general form. It looks frightening; read it piece by piece.

\[ \underbrace{\nabla_\theta J(\theta)}_{\textcolor{#2a78d6}{\text{how to change }\theta}} = \mathbb{E}\Big[\sum_t \underbrace{\nabla_\theta \log \pi_\theta(A_t \mid S_t)}_{\textcolor{#2a78d6}{\text{make the action more likely}}}\ \cdot \underbrace{\Psi_t}_{\textcolor{#2a78d6}{\text{how good it was}}}\Big] \]

Increase the probability of each action in proportion to how good it was.

If Ψ is positive the action becomes more likely; if negative, less likely. The rule actually run, one step at a time: \(\theta \leftarrow \theta + \alpha\, \Psi_t\, \nabla_\theta \log \pi_\theta(A_t \mid S_t)\).

Key idea: the policy gradient pushes up the probability of each action in proportion to how much better than expected it was.

05Factor 1: making an action more likely

A few separate actions. Each action has a preference θ; the softmax turns preferences into probabilities that add up to 1. Raise one preference and the others' probabilities fall: a tug of war.

\[ \pi(a \mid s) = \frac{e^{\theta_a}}{\sum_b e^{\theta_b}} \]

Softmax tug of war

Drag the preferences.

A continuous action, such as a motor force: the policy is a bell curve with a mean and a width; an action is a number drawn from it. If a sampled action turned out well, drag the mean towards it; widen the curve if good actions lie far from the mean, narrow it if they are close. A robot with several joints simply has one bell curve per joint.

Learning a continuous action

Hidden from the learner: the best action is 1.5. Reward = −(a − 1.5)². Each red dot is one try.

The advantage

Not "how good is this action?" but "how much better is it than the average action in this state?" The signed surprise of Part 4 is exactly the number a policy needs.

07Actor and critic

The actor is the policy: it acts and improves. The critic is a value function: it does not act, it judges, using the TD error. One signal, δ, teaches both.

\[ \begin{aligned} \delta &= R + \gamma V(S') - V(S) && \text{(the critic's surprise)} \\ V(S) &\leftarrow V(S) + \beta\,\delta && \text{(critic)} \\ \theta(S, a) &\leftarrow \theta(S, a) + \alpha\,\delta\,\big(\mathbb{1}[a = A] - \pi(a \mid S)\big) && \text{(actor)} \end{aligned} \]

α = β = 0.2, γ = 0.8. No ε: the randomness is the policy itself.
